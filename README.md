# Menfess Sumatra

Website menfess anonim dengan Telegram dan sistem pembayaran QRIS.

## Features
- Submit text/photo
- Telegram auto post
- Tripay payment
- Supabase database
- Admin approval

## Stack
- Node.js
- Vercel
- Supabase
- Telegraf

## Flow
1. User submit menfess
2. User bayar QRIS
3. Tripay callback
4. Telegram posting otomatis

## ENV
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHANNEL
- SUPABASE_URL
- SUPABASE_ANON_KEY
- TRIPAY_PRIVATE_KEY
